# College To-Do List 🎓

A beginner-friendly student project made with HTML, CSS, and JavaScript.

## Features
- Add college tasks
- Mark tasks as completed
- Delete tasks
- Filter All, Active, and Completed tasks
- Saves tasks in browser localStorage
- Responsive design

## How to Run
1. Download or extract the ZIP file.
2. Open `index.html` in a web browser.
3. Start adding your college tasks.

## Technologies
- HTML
- CSS
- JavaScript
- LocalStorage
